# Contributing

Thank you for helping. The full guide is a page of the wiki itself: [wiki/about/contributing.md](wiki/about/contributing.md).

In short:

- Cite a source others can read for every factual statement, and write in your own words.
- Do not add unreleased reports, slides, data or photographs, whoever made them, without the rights holder's permission. Keep such material in the Git-ignored `pending/` folder until it is cleared.
- Run `node build.mjs` before opening a pull request and fix every error it reports.
- Text and original figures you contribute are published under CC BY 4.0, and code under the MIT licence.
