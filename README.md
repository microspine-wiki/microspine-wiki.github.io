# Microspine Wiki

An open, community-maintained handbook on microspines and spine-based climbing: how small steel hooks on compliant suspensions hold on rough surfaces, how to design, build and test spine arrays, and what the robots, aircraft and human-scale devices that used them have taught.

**Read it at <https://microspine-wiki.github.io/>.**

The wiki is plain Markdown in [`wiki/`](wiki/README.md). It reads as it is on GitHub and in Obsidian, and a small generator with no dependencies turns it into a static website with search, figures, typeset math, two interactive models and a small archive of videos.

## Build and preview

You need [Node.js](https://nodejs.org/) 20 or later. There is nothing to install.

```sh
node build.mjs                # build the site into _site/ and check it
node build.mjs --serve        # preview at http://localhost:4173, rebuilt on every change
node build.mjs --standalone   # self-contained pages in _preview/, to open straight from disk
node build.mjs --public       # leave out the local pending/ folder (always on in CI)
```

The build fails on a broken link or anchor, a missing image or alt text, math that does not parse, and third-party media not listed in [`wiki/about/credits.md`](wiki/about/credits.md).

Other scripts:

| Command | What it does | Needs |
|---|---|---|
| `node figures/build.mjs [name …]` | redraws the original figures in `wiki/assets/figures/` | Node.js |
| `python3 tools/make_bibliography.py` | regenerates `wiki/reference/bibliography.md` from `data/references.json` | Python 3 |
| `python3 tools/stalk_model.py` | prints loading lines of the compliant-stalk model | Python 3 (matplotlib for `--plot`) |
| `python3 tools/climber_loads.py` | best-case pad loads of a four-limbed climber on a vertical wall | NumPy, SciPy |
| `python3 tools/extract_thesis_figures.py thesis.pdf` | cuts the reproduced figures out of the thesis PDF | Pillow, poppler's `pdftoppm` |

## Publish

[`.github/workflows/pages.yml`](.github/workflows/pages.yml) builds the public site and deploys it to GitHub Pages on every push to `main`. In the repository's settings, set Pages to deploy from GitHub Actions. Then fill in `repository` and `siteUrl` in [`site.config.mjs`](site.config.mjs) to switch on the GitHub link, the "edit this page" links, canonical addresses and the sitemap.

## Layout

| Path | Contents |
|---|---|
| `wiki/` | the pages; `wiki/SUMMARY.md` is the sidebar |
| `wiki/assets/figures/` | original figures (SVG, generated by `figures/`) |
| `wiki/assets/thesis/` | figures reproduced from Asbeck 2010, under that work's licence |
| `wiki/assets/archive/`, `wiki/assets/video/` | photographs and videos from the Stanford laboratory's project wikis |
| `data/references.json` | the bibliography, one entry per work |
| `figures/` | figure scripts and their shared helpers ([conventions](figures/README.md)) |
| `tools/` | Python reference implementations and maintenance scripts |
| `theme/` | stylesheet, page script and interactive widgets |
| `build.mjs`, `lib/` | the site generator |
| `vendor/` | markdown-it and KaTeX, unmodified, with their licences |
| `pending/` | optional, ignored by Git: local drafts that are not cleared for release |
